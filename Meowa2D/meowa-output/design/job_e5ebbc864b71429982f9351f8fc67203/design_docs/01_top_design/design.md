# 顶层设计

## 设计目标

让玩家在15—30分钟内学会并掌控一套少而深的动作：走、跑、跳、悬挂、攀爬、拔刀/收刀、攻击、受击与机关交互。每个屏幕都以一个可读的危险问题为中心，并用灯笼将失败成本压缩到可接受范围。

## 核心推动力

 玩家推动力是“月门就在前方，但沙漏不会等我”。外在目标是月钥与月门；内在回报是从观察、试错到熟练的掌控感。回报以新路线、灯笼安全感、机关打开的空间和短暂安静镜头呈现，不用金币或经验制造虚假成长。

## 大循环

 从灯笼出发 → 观察屏幕布局和陷阱周期 → 选择上层/下层路径 → 用平台动作越过危险 → 在单人战斗中维持距离并找破绽 → 操作压力板/拉杆/链条 → 触发路线改变 → 到达下一盏灯笼 → 重复，最终取得月钥并抵达月门。

## 小循环

 读预兆（沙粒、机关闪光、敌人起手）→ 调整站位 → 在窗口内输入动作 → 立即获得位置、机关状态或敌人硬直反馈 → 重新观察。一个小循环控制在3—12秒；失败后从最近灯笼快速回到同一学习点。

## 最小体验单位

 一次“危险通过”：玩家看到一个陷阱或守卫前摇，决定等待/跳跃/悬挂/交战，完成一次有明确结果的动作。最小单位必须能在单屏内独立理解，且不依赖收集品。

## 核心活动流程

 1. 灯笼点亮并记录位置、生命和已完成的永久机关状态。
 2. 进入新屏幕，镜头展示主要垂直关系和沙漏HUD。
 3. 玩家以走/跑/跳/悬挂/攀爬处理平台与陷阱。
 4. 遇到守卫时锁定为一对一战斗空间，攻击、后退、格挡式接刀与推拉距离决定胜负。
 5. 操作压力板、墙面拉杆或悬链改变门、砖块和陷阱状态。
 6. 触发下一盏灯笼；受伤则用牛奶碗恢复，死亡回到灯笼。
 7. 取得月钥，穿越最终机关并在月门插入月钥。

## 关键决策与张力

- 赶路还是观察：时间收益对抗陷阱信息。
- 上层还是下层：上层更快但跳跃精度要求高，下层更绕但有可控的链条和灯笼。
- 立刻出刀还是拉开距离：出刀可抢先，错误时机将被守卫压入危险地形。
- 喝奶还是保留：牛奶碗是有限的场景资源，恢复生命但占用一次安全余量。
- 拉杆先后顺序：某些门只在短时间内开启，路线选择影响剩余沙漏。

## 节奏结构

 8—12屏分为：教学安全段（1—2）、基础陷阱段（3—4）、首个守卫与路线分叉（5—6）、垂直链条/塌砖复合段（7—8）、多系统回收与钥匙前压力（9—10）、沙漏封锁倒计时下的终段和月门（11—12，可按屏幕预算合并）。每段先单独引入规则，再复合；不在同一屏首次引入两个致命规则。

## 输入、输出与反馈

 建议键位：A/D或方向键移动；Shift跑步；Space跳跃；S/下方向下蹲、下落或从边缘放手；J攻击；E交互/拾取/使用牛奶；Esc暂停。输入可重绑。

 输出反馈：角色姿势、脚步与落地尘粒、刀刃闪点、受击闪白、陷阱预警、灯笼火焰、门和沙漏状态。屏幕不堆叠文本，交互使用简洁爪印提示。

## 范围与非目标

 范围：一名主角、四类敌人、一个小Boss、8—12屏、一个月钥目标、固定机关与检查点、完整始末演示。

 非目标：技能树、装备稀有度、金币商店、随机地图、多人、复杂对话、开放世界、连招系统、可玩猫科角色选择。

## 实现基准

- 以12个逻辑屏幕作为完整目标；若制作周期压缩，可合并第9与第10屏，但不得删除月钥、精灵井和月门收束。
- 首次完整探索的目标是抵达终点时剩余沙漏的10%—20%；熟练路线目标为35%—50%。这是调参验收线，不是玩家可见的评分。
- 死亡立即回到最近灯笼；死亡重试不额外扣除沙漏，避免失败滚雪球。沙漏归零则触发“宫门封闭”演出，再允许从最近灯笼重新尝试。
- 任何致命陷阱必须先有至少一种可辨预兆；不可用随机刷新或屏外伤害制造难度。
